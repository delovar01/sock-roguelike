# Носок-одиночка

Top-down roguelike на Python + pygame. Носок ищет свою пару в трубах
стиральной машины. 5 уровней с процедурной генерацией. На каждом надо
найти ключ и дойти до выхода, попутно драться с молью и пауками.

## Запуск

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Управление

- WASD / стрелки — двигать носок (можно удерживать)
- Шаг на врага — удар вместо движения
- Пробел — удар в 4 соседние клетки сразу
- Esc — пауза. В паузе Q — в меню, + / - — громкость
- F3 — отладка

## Что собирать

- Пуговица — лечит на 1 HP
- Иголка — +1 к урону навсегда
- Ключ — открывает выход с уровня

## Тесты

```
pytest tests/ -v
```

16 тестов, ~1 секунда.

## Структура

```
src/
  core/         цикл, константы, ввод, ресурсы
  scenes/       меню, игра, смерть, победа
  entities/     игрок, враги, предметы
  systems/      движение, столкновения, ИИ, отрисовка
  algorithms/   BSP-генерация, A* поиск пути
  world/        тайлы, уровень, камера
  ui/           меню и HUD
  persistence/  сохранения JSON
```

## Стек

- Python 3.12
- pygame 2.5.2
- pytest 8.0
